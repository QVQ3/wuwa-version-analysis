结论

  • 早期慢、后来提速并趋稳：1.x 时代约 45 天一个版本，进入 2.x 提速到约 40 天，3.x 延续并稳定。
  • 大版本前明显拉长：1.4→2.0 隔 49 天，是全周期最久，符合"憋大版本"的直觉。
  • 整体稳定在 6 周左右：22 个版本约 860 天，平均 41 天。

用到的 SQL 知识

julianday() 日期转天数 自连接 相关子查询 CAST 取主版本号 GROUP BY + AVG/COUNT ROUND 四舍五入

核心查询

SELECT
  CAST(a.ver AS INTEGER) AS 大版本,
  COUNT(*) AS 间隔个数,
  ROUND(AVG(julianday(b.release_date) - julianday(a.release_date)), 1) AS 平均间隔
FROM version a
JOIN version b
  ON b.ver = (SELECT MIN(ver) FROM version WHERE ver > a.ver)
GROUP BY CAST(a.ver AS INTEGER)
ORDER BY 大版本;
